## How to use this register

1. **Sort by Severity × ROADMAP horizon.** Never start a HIGH while a CRITICAL is open.
2. **Cluster by shared files.** Gaps citing the same source file should be fixed together.
3. **Update dual-write:** when you resolve a gap, mark it ✅ here AND in the source AI_CONTEXT file.
4. **Re-extract weekly:** rerun the script to catch drift.

## Legend

- **ID** — sequential G-001..G-NNN (this register's own numbering)
- **Orig ID** — the G# from the source file (e.g. G1, G7)
- **Severity** — CRITICAL / HIGH / MEDIUM / LOW / WONTFIX (MAJOR→HIGH, MINOR→LOW, UNKNOWN=untriaged). WONTFIX = false positive / not actionable. Manually-triaged severities for UNKNOWN gaps are preserved across re-extractions via `readSeverityOverrides()`.
- **Sector** — which AI_CONTEXT subfolder
- **Source** — `path/to/file.md:line`
- **Code ref** — `laravel/path:line` if cited
- **Summary** — one-line description
- **Blocks** — what is blocked (cutover / RLS audit / API phase / etc.)
- **Horizon** — H1/H2/H3/H4 from ROADMAP.md (best judgement)
- **Status** — open / in-progress / resolved / wontfix
- **Resolved** — commit hash that closed this gap (or `—` if open)
