## 8. Methodology & reproducibility

The sweep script is version-controlled in the repo at
`docs/help-sweep/phase6_sweep.py` (paths resolve relative to the script, so it runs
from either the in-repo copy or the `parse_work/` working copy).

```bash
# Re-run the sweep (idempotent; regenerates matrix + report):
python3 docs/help-sweep/phase6_sweep.py
```

`routes.tsv` was found at `/home/z/parse_work/routes.tsv`; Sweep C ran.

The sweep is **static** (no PHP runtime, no Laravel router). It parses the PHP
registry files with regex, re-expands `Route::resource()` declarations manually,
and simulates `HelpService::menuKeyForRoute()`'s 4-layer chain in Python. The
matrix CSV (`docs/help-coverage-matrix.csv`) has one row per route with columns:
`source, route_name, uri, controller, action, csv_menu_key, resolved_layer,
resolved_menu_key, content_exists, csv_match, module`.
